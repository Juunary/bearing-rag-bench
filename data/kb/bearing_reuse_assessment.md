# 분해한 베어링의 재사용 판정

## 원칙
- 분해(탈거) 자체가 베어링에 손상을 줄 수 있어 **대형·고가 베어링**이거나 정기 점검으로 분해한 경우에만 재사용을 검토하고, 소형 범용 베어링은 교체가 경제적입니다.
- 풀러를 **외륜에 걸어 내륜을 뺀** 베어링(궤도에 하중이 통과)은 압흔 위험 때문에 원칙적으로 재사용하지 않습니다. 내륜은 내륜 풀러, 외륜은 외륜 풀러로.

## 세척과 검사 순서
1. 경유·세척유로 세척, 압축공기로 돌리지 않음(고속 공회전은 손상 원인).
2. 손으로 천천히 돌려 **걸림·거칠음·소음**을 느낍니다. 걸림이 있으면 세척 반복 후 재확인, 여전하면 불합격.
3. 궤도·전동체 육안 검사(확대경 10배): 박리·압흔·균열·변색·녹·전식 무늬·마모 띠.
4. 케이지: 변형·마모·리벳 풀림, 전동체 포켓 마모.
5. 씰·실드(밀봉 베어링): 변형·립 손상. 밀봉 베어링은 세척·재급지가 어려워 보통 교체.
6. 치수·틈새: 레이디얼 틈새를 측정해 원래 등급 허용 범위(마모로 늘어난 양이 초기 틈새의 수십 % 이내) 확인. 끼워맞춤 자리면의 크리프 흔적.

## 판정 기준
| 상태 | 판정 |
|---|---|
| 궤도에 박리·균열·전식 플루팅 | 불합격 |
| 압흔(브리넬링), 거짓 브리넬링 자국 | 불합격 |
| 변색(청·갈색 템퍼 색)으로 과열 흔적 | 불합격(경도 저하 가능) |
| 얇은 녹·얼룩이 세척으로 제거되고 피팅 없음 | 조건부 합격 |
| 궤도에 균일한 무광 하중 띠, 결함 없음 | 합격(정상 런인) |
| 케이지 마모·변형 | 불합격 |
| 틈새 증가 과다, 축 방향 덜걱거림 | 불합격 |

## 재사용 시 처리
- 세척 후 즉시 방청유 도포, 재급지(새 그리스로 지정량), 조립 전까지 포장 보관. 원래 **같은 위치·같은 방향**으로 조립하면 런인 상태가 유지됩니다.
- 재사용한 베어링은 교체 이력에 기록하고 진동·온도 추세 감시를 강화합니다.
