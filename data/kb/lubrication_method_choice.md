# 윤활 방식 선택: 그리스와 오일

## 기본 원칙
- 구름 베어링의 약 90%는 **그리스**로 윤활합니다. 밀봉이 간단하고 보수가 적으며 누설이 없기 때문입니다.
- **오일**은 고속(dn값이 높을 때), 고온(열을 밖으로 실어 내야 할 때), 기어와 같은 오일을 쓰는 하우징(기어박스), 또는 냉각이 필요할 때 선택합니다.

## 그리스가 적합한 경우
- 저~중속, 정상 온도(-30~+120 °C 범위에서 증주제·기유에 맞춤), 밀봉 베어링(2RS·ZZ)처럼 재급지가 어려운 위치.
- 수직축·경사축처럼 오일이 흘러내리는 위치.
- 한계: 열 방출이 거의 없고, 과충전 시 교반 발열(처닝)로 온도가 오릅니다. 초기 충전량은 베어링 내부 공간의 30~50%가 기준이며 고속일수록 적게 넣습니다.

## 오일 윤활 방식
| 방식 | 적용 속도 | 특징 |
|---|---|---|
| 오일 배스(유욕) | 저~중속 | 정지 시 유면이 최하단 전동체 중심 높이. 유면이 높으면 교반 발열 |
| 비말(splash)·오일 링 | 중속 | 기어·링이 오일을 튀겨 공급, 기어박스에서 흔함 |
| 순환 급유 | 중~고속 | 펌프로 공급·회수, 필터와 쿨러로 열·오염 제거. 대형 설비 표준 |
| 오일 제트 | 고속 | 노즐로 베어링 내부에 분사, 항공 엔진·터빈 |
| 오일 미스트 | 고속 | 압축공기에 오일을 안개로 섞어 공급, 소량으로 냉각, 환경 배출 문제 |
| 오일 에어 | 초고속 주축 | 압축공기로 극소량 오일을 간헐 공급, 미스트보다 배출이 적음 |

## 점도 선택
- 운전 온도에서의 동점도가 베어링이 요구하는 **기준 점도(ν1)** 이상이어야 윤활막이 형성됩니다. 점도비 κ = ν/ν1가 1 미만이면 혼합 윤활로 수명이 줄고, 1~4가 적정입니다.
- 기유 점도는 저속·대형일수록 높게, 고속·소형일수록 낮게 고릅니다. ISO VG 등급은 40 °C 점도이므로 운전 온도로 환산합니다.

## 전환 시 주의
- 그리스에서 오일로 바꾸면 밀봉 방식(래디얼 샤프트 씰·래버린스)과 유면 관리가 필요합니다. 오일에서 그리스로 바꾸면 열 방출이 사라지므로 속도·온도 여유를 다시 확인합니다.
